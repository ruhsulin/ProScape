🏝️ ProScape - Resort Management Application

ProScape is a full-featured resort management web application built with ASP.NET Core MVC, Entity Framework Core, and ASP.NET Core Identity using the Clean Architecture approach.

✨ Features
🏨 Villa Booking System – Customers can browse villas and book rooms.
🔐 Authentication & Authorization – Secure user login with ASP.NET Core Identity.
💳 Stripe Payment Integration – Process payments securely for bookings.
📊 Admin Dashboard – Manage villas, view bookings, and check-in/out guests.
📈 Charts & Reports – Visual data representation for better insights.
📂 Dynamic Exporting – Generate PDF, PPT, and Word reports dynamically.
🏗 Clean Architecture – Follows a well-structured architecture with Repository & Service layers.
🚀 Deployment Ready – Can be deployed to MyWindowsHosting or other hosting services.

🛠 Technologies Used
.NET 8 – Latest version of ASP.NET Core MVC
Entity Framework Core – ORM for database interactions (Code-First Migrations)
ASP.NET Core Identity – User authentication and role-based authorization
SQL Server – Database management
Stripe API – Payment processing integration
Chart.js – Data visualization for admin insights
Bootstrap & jQuery – Responsive frontend design
Dynamic Document Generation – Exporting PDF, PPT, and Word reports
