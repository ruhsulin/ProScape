# 🏝️ ProScape - Resort Management Application  

**ProScape** is a full-featured **resort management system** built with **ASP.NET Core MVC, Entity Framework Core, and ASP.NET Core Identity**, following the **Clean Architecture** approach.  

---

## ✨ Features  

✅ **Villa Booking System** – Customers can browse villas and make bookings.  
✅ **Authentication & Authorization** – Secure user login with **ASP.NET Core Identity**.  
✅ **Stripe Payment Integration** – Accept online payments for bookings.  
✅ **Admin Dashboard** – Manage villas, view bookings, and check-in/check-out guests.  
✅ **Charts & Reports** – Visual representation of data for better insights.  
✅ **Dynamic Exporting** – Generate **PDF, PPT, and Word** reports dynamically.  
✅ **Clean Architecture** – Well-structured project with **Repository & Service layers**.  

---

## 🛠 Technologies Used  

🔹 **.NET 8** – Latest version of **ASP.NET Core MVC**  
🔹 **Entity Framework Core** – ORM for database management (Code-First Migrations)  
🔹 **ASP.NET Core Identity** – User authentication & role-based authorization  
🔹 **SQL Server** – Database storage & management  
🔹 **Stripe API** – Payment processing integration  
🔹 **Chart.js** – Data visualization for admin dashboard  
🔹 **Bootstrap & jQuery** – Responsive frontend UI  
🔹 **Dynamic Document Generation** – Export **PDF, PPT, and Word** reports  
🔹 **Azure/MyWindowsHosting** – For cloud deployment (if applicable)
